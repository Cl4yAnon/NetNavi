[ CORE COMMANDS ]
  connect <ip>         - Initialize target gateway audit (e.g., connect 192.168.1.1)
  show quick scan      - Display active cached scan/audit results from memory slot
  delete quick scan    - Flush and delete cached scan results from active memory
  clear                - Refresh the NetNavi dashboard UI and live WLAN sweep
  help                 - List all available operational commands
  exit / quit          - Safely shut down the NetNavi C2 dashboard
